第 3 题 单选题 答错 来源 · 《考研数学强化通关330》概率论与数理统计

三车间次品溯源 · 全概率与贝叶斯

某工厂的甲、乙、丙三个车间生产同一种零件，产量依次占全厂的 25%、35%、40%，次品率分别为 5%、4%、2%。现从全厂成品中随机抽取一件，发现是次品，则它来自乙车间的概率为（　　）

答错了 · 正确答案 B 已计入错题本，轮次结束后可再练

全概率：P(B) = 3Σi=1 P(Ai)P(B|Ai) = 0.25×0.05 + 0.35×0.04 + 0.40×0.02 = 0.0345

贝叶斯：P(A2|B) = 0.35 × 0.040.0345 = 1434.5 = 2869 ≈ 0.406

你选的 A（25/69）其实是 P(A1|B)——来自甲车间的概率。三个后验之比为 25 : 28 : 16，乙最大，与其「先验 35% × 次品率 4%」的乘积最大一致。

设 A 为 3 阶矩阵，其特征值为 1、2、3，则 |2A| = （　　）

答错 · 你选 C，正确答案 D 连续两轮同类错因，已提升复习优先级

|kA| = kn|A|（n 为阶数）。|A| = 1×2×3 = 6，故 |2A| = 23·6 = 8×6 = 48。

常见失误：只乘 2 得 12，或把 23 误算成 6 得 36——本题错因属后者。记住标量乘法作用于每一行，行列式放大 kn 倍。
