判断：运行以下 C 程序段后，输出的 s 值为 15。 

/* 循环 5 次，每次把 i 累加进 s */
int s = 0;
for (int i = 1; i <= 5; i++)
    s += i;
printf("%d", s);
答对 你的答案 正确　·　命题成立

循环变量 i 依次取 1 至 5，每轮执行 s = s + i，故循环结束时 s = 1 + 2 + 3 + 4 + 5 = 15，与命题一致，输出 15。

判断题 数学一 · 660 题 · 极限与连续

判断：函数 f(x) = x · sin1x 在 x = 0 处连续（  ）

答错 你的答案 正确　·　正确答案 错误

函数在一点 x = 0 处连续，需同时满足三个条件：① f(0) 有定义；② limx→0f(x) 存在；③ 极限值等于函数值。

本题中 x · sin(1/x) → 0（有界量 × 无穷小），极限存在且为 0；但 f(x) 在 x = 0 处无定义，条件 ① 不满足，故不连续。若补充定义 f(0) = 0，则 f 在该点连续（可去间断点）。
