# 单题计时切换（focus-timer）出稿任务书

> 本目录是 OpenDesign 出稿工作区。OD run 对既有文件只读，**禁改本 README**。

- 主题：单题计时切换（focus-timer）。
- 交互链：多题长卷（现状形态勿改）→ 非焦点卡降亮度（可见但明显退后，
  opacity≈0.22、字色压到几乎读不进——暗到难受才会触发点击的动机设计），焦点卡
  正常亮度 → 点击任意非焦点卡立即切焦点（亮度过渡 ≤150ms）→ 点选项作答本身
  即点击切换 → 提交判分后该题用时冻结，卡上有「本题用时 m:ss」注记。
- **焦点卡边框流光（计时可视化）**：一道亮色流光沿焦点卡边框匀速绕行，
  **转一圈＝1 分钟（60s linear）**；流光**头部**随行显示当前用时「m:ss」；
  圈数（即分钟数）在卡上可见（题头或角落小 chip）。提交判分后流光停格并淡出，
  留下静态用时注记。
- **悬停零视觉变化**（无抬亮无任何反馈，悬停不切焦点）；滚动同样不切。
- 作答必须点击（点选项本身就是切换动作，机制上保证「作答必先计时」）。
- 视觉差异只有两条：焦点/非焦点亮度分级 + 焦点卡边框流光，其他视觉设计不加。

## 屏清单（同一张 HTML 内分区呈现，标注屏号）

1. 全景：多题长卷，焦点在第 3 题左右，其中含一张材料组卡。
2. 切换瞬间前后对照（两张并排）。
3. 焦点卡作答态：选中 chip → 提交揭示 + 用时注记。
4. 头部计时标签 + 题号栏（NumRail）焦点题指示。
