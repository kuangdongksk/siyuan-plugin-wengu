单题计时切换 · 焦点即计时

长卷形态一律不动：只在「谁是焦点」上加一条视觉分级——焦点卡满亮度，其余卡退到 0.22 亮度；滚动与悬停都不切焦点，点击才切，而点选项作答本身就是切换动作，机制上保证「作答必先计时」。提交判分时该题用时冻结，落成卡上「本题用时 m:ss」注记。下面四屏依次是：多题长卷全景、切换瞬间前后对照、焦点卡作答态、以及头部计时标签与题号栏的焦点指示。作用面仅限刷题主区的长卷视图；侧栏、开刷面板、轮次报告、错题本与移动端未动。

① 点击才切　滚动不触发、悬停不触发；只有 pointer 点击改焦点。

② 过渡 150ms linear　两卡交叉淡化，亮度和恒定，过程里不出现「暗谷」。

③ 只此一条视觉　不加焦点边框、不加放大位移、不加投影；卡内结构文案顺序逐字不变。

④ 0.22 / 0.45 / 1.00　非焦点 / 非焦点悬停 / 焦点。

⑤ 提交即冻结　该题用时＝它处在焦点的时间之和，判分落定格上「本题用时 m:ss」。

⑥ DOM 零变化　焦点只切一个 class（.is-focus）与一个 aria-current，不做重排。

1.00 · 焦点卡
0.22 · 非焦点卡
0.45 · 非焦点·悬停

三张缩样就是卡面真值：同一张卡换的只是透明度，颜色、字号、间距、结构一概不动。键盘 Tab 到卡上时同样抬到 1.00，与焦点态一致。

① 全景 · 多题长卷（焦点落在第 23 题，卷内含一张 24–25 材料组）。滚动窗职责不变：卡自上而下堆叠，焦点卡满亮度可作答，上下相邻卡退到 0.22——可见、可辨，但明显不在当下。点任意非焦点卡的任意位置（含它的选项）即把焦点切过去。材料组按「组内小题各自计时」处理：焦点在组外时组头与材料一同退后，焦点进组后组头与材料回到满亮度，组内非焦点小题照旧 0.22。

可交互：点卡体切焦点（两卡在 150ms 内真的交叉淡化，不是瞬时跳变）、点选项作答、点「提交答案」判分，「下一题」交给下一张卡；头部「本题」随焦点走秒。窗口内滚动不会改变焦点。

可交互：点左格内第 22 题卡的任意位置 → 两卡交叉淡化；点「重放 150ms 过渡」则复位到起始帧再走一遍，时间线的当前档与下方读数同步推进。读数取自元素实时的 computed opacity，不是写死的中间值。

切换时序 · 屏 ②
时刻 写进 DOM 的东西 口径
t = 0 旧焦点卡 remove .is-focus；新焦点卡 add .is-focus 同一帧内完成，中间不出现两卡同亮或同暗的过渡帧。
t = 0 → 150ms transition: opacity 150ms linear 只过渡透明度；不加 transform、不加 box-shadow 过渡，避免焦点切换触发重排。
t = 150ms 题号栏 .qn.cur 与头部「本题」同帧已就位 三处指示（卡亮度 / 题号栏当前格 / 头部本题）在 150ms 内收敛到同一题。
切换时的时间账 旧焦点题 acc 累加停在当前值（未提交则保留） 切走不清零：切回来接着累加，提交才冻结。

③ 焦点卡作答态 · 选中 → 提交揭示 → 用时注记。焦点卡可直接作答：点选项即选中（这一下同时就是切焦点的动作，所以不存在「没在计时却已作答」的路径），头部「本题」实时走秒；提交判分后该题用时冻结，卡头出现「本题用时 m:ss」注记，题号栏对应格同时着色。

可交互：点 A–D 选择、点「提交答案」判分并冻结用时、点「下一题」把焦点交给下一张卡。上方第 22 题是已判分冻结态的对照——同一个用时数字在判分行里也能读到（卡头注记在它自己的卡头上，上滚可见）。

作答态三帧 · 屏 ③
状态 卡上出现什么 口径
焦点降临（未作答） 卡头无用时注记；头部「本题」从 0:00 起走 计时起点＝该题第一次成为焦点，不是「点第一个选项」。
已选中（未提交） 选项走 .sel：陶土橙描边＋浅底，字母徽标实心 选中归属焦点卡；改选随便改，用时继续累加，不算次数。
提交判分 「本题用时 m:ss」chip 落到卡头；选项锁定，正确项 .ok、误选项 .bad；展开解析、考点、自评 冻结那一刻的 acc；此后无论切走多久，这个数字不再变。
用时出现几处 两处：卡头 .chip.c-time（常驻）＋ 判分行（冻结那一刻） 同一个数字、两个用途：卡头是记录（卡被降亮度或滚回去看时仍在），判分行是当时的反馈。
判分后的干扰项 .opt.dim 只压文字色（--muted），不叠 opacity 卡体已经带着 0.22 的焦点亮度；干扰项再乘一次透明度就叠到约 0.13、几乎读不出来。与材料组「不做嵌套相乘」同一条口径：退后只压一层。
注记形态 .chip.c-time（计时图标＋等宽数字） 与题型 chip 同一行、同一套胶囊语言，不新增组件、不占用题干空间。
判分后的焦点 焦点不动，仍停在这张卡（可回看解析） 「下一题」才移焦点；直接点别的卡也算一次点击切换。

④ 头部计时标签 ＋ 题号栏（NumRail）焦点题指示。题号栏不需要新状态——焦点题就是当前题，沿用既有 .qn.cur 语义与陶土橙实底（填充走 --primary-strong，与主按钮同一口径），零新增状态、零新增徽标。头部把「本题」放在「本轮」之前：前者是随焦点走的单题计时，后者是本轮总时。点题号栏任意格即切焦点并滚到该卡，头部「本题」与该格同帧更新。

落点① 卡头注记

提交判分后出现，值是冻结值。卷内已判分的题各自带一个，回看时不用去想「刚才那题花了多久」。

落点② 头部「本题」

实时值，跟随焦点切换表盘：焦点在谁身上，它就跑谁的账。计时中图标走主色，冻结后转弱灰。

落点③ 题号栏当前格

沿用 .qn.cur。它本来就代表「当前题」，焦点即当前题，因此一个状态类都不用加。

交互口径：什么会切，什么不会

  • 滚动　不切。卷内不存在任何 scroll → 焦点 的通路，机制上做不到。
  • 悬停　不切。悬停只把卡从 0.22 抬到 0.45，纯提示。
  • 点击卡体　切。卡的任意位置（含题干、空白）都算一次点击。
  • 点选项　切＋选。作答动作本身就是切换动作，故「作答必先计时」成立。
  • 点题号栏某格　切＋滚到该卡；这是键盘用户的主路径。
  • 提交判分　不切。焦点留在原题，方便对着解析回看自己的用时。
  • 点「下一题」　切到下一张卡（含材料组内的下一小题）。

计时口径：一题一笔账

  • 起　该题第一次成为焦点的时刻。进入长卷时焦点落在第 23 题，它即刻开始计时。
  • 累　＝该题处在焦点的时间之和。切走不清零，切回来接着加。
  • 冻　提交判分（或标不会）那一刻定格，此后不再变。
  • 材料组　按小题各记一笔：组壳与材料不单独计时，焦点进组后由当前小题承担。
  • 一轮结束　交卷即封账；错题重刷是新一轮，从 0:00 重记。
  • 静置　同一张卡一直挂着焦点、人离开电脑，时间照走——不做空闲检测，这不在本稿范围。

不做清单（本稿的克制面）

  • 不加焦点边框、不加外发光、不加投影变化。
  • 不做缩小 / 位移 / 盖叠，非焦点卡的盒子位置逐像素不动。
  • 不改卡内结构、文案、顺序，不加「计时中」徽标或角标。
  • 不给非焦点卡加遮罩层或模糊，退后只由透明度承担。
  • 不改侧栏、开刷面板、轮次报告、错题本与移动端——作用面只有长卷。

可及性：0.22 是有代价的，代价写在这里

  • 先把账算清楚　按 sRGB 相对亮度＋alpha 合成估算，卡面正文（--fg）在 0.22 下约 1.6:1、0.45 下约 2.5:1，都低于 4.5:1。这是「可见但明显退后」的必然结果，不辩解。
  • 为什么不把 0.45 再抬高　要抬到 4.5:1 得上到 ≈0.82，与焦点态几乎看不出区别，那条分级就没了。所以兜底放在通路而不是取值上。
  • 悬停抬亮　0.45 只定位为「目标拾取」提示，不当可读性解药。
  • 键盘路径不经低对比态　Tab 到卡上或选项上即回 1.00，键盘用户读到的永远是满亮度。
  • 导航不降亮　题号栏、头部统计条、滚动条一律不参与降亮度，方向感始终清晰。
  • 读屏　焦点题带 aria-current="true"，非焦点卡仍在 DOM 顺序内、可被朗读。

--focus-lift 0.45 非焦点卡悬停：仅作目标拾取提示，可读性由焦点态与键盘态承担。

.chip.c-time 卡头注记：计时图标＋等宽「本题用时 m:ss」 只在 submitted 后渲染；颜色走既有 chip 语言。
运行时 一枚 1s interval 推进焦点题的 acc 只改头部与注记的文本节点，不重渲染卡体，避免滚动跳动。
窄屏（≤1180px） 稿纸层隐藏 dock 与侧栏、双取景窗改单列 属稿件阅读模式，不是产品改动；产品移动端适配另案（移动端刷题见 mobile 域）。
prefers-reduced-motion --focus-ms: 0ms 系统开启「减少动态效果」时过渡归零，切换即时到位；亮度分级本身不动，机构上仍是「一条亮度」。
卡内 DOM 就地换掉后的键盘焦点 root.focus({ preventScroll: true }) 选中/判分把卡内节点换新，原本持焦的按钮随之消失——把焦点收回取景窗本体，鼠标作答之后 A–D 与 Enter 仍然是活的。产品侧同理：作答后别把焦点丢给 body。
data-od-id 唯一化 四格取景窗各自加前缀（pano- / answer- / rail- / pane-before-） 同一张卡在四格取景窗里各有一份，锚点重名会让批注指不清是哪一个；只改稿件的锚点名，界面零变化。
阅读位置记忆 localStorage["wengu-focus-timer:view"]（六段之一） 刷新回到上次读到的那一屏；localStorage 不可用（无痕 / 受限 iframe）时咽掉异常、退回首屏，不阻断阅读。
打印 / 导出 PDF 导航条让位；屏、取景窗、卡与表行 break-inside: avoid 纸张与 PDF 上不给「一句话断两页、一张卡切成两半」；print-color-adjust: exact 让深色底照印，观感与屏幕一致。
