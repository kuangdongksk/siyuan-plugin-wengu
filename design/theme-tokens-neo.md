# 温故桌面端 · 现有主题令牌（来自运行中的思源 3.8.3 + Neo+ 主题，2026-09-13 实测计算值）

用户当前运行的是 **Neo+ 第三方主题的深色暖调模式**——桌面端设计必须与这套气质一致，
不要用移动端稿的白底明亮风。

## 语义色约定（温故既有）

- 正确/答对：绿（参考截图里正确选项的绿字 + 绿边框）
- 错误/答错：红（错误选项红字；题号栏答错格红底）
- 进行中/当前：主色陶土橙（侧栏选中项橙色描边、题号栏当前题橙底）
- 完成态徽标：绿；未开始：弱灰

## 字体

`"PingFang SC", "Hiragino Sans GB", "Source Han Sans SC", "Microsoft Yahei", sans-serif`
（系统栈，不做自定义字体）

## 温故桌面的结构语言（从运行截图归纳）

- 布局 = 思源页签内：左侧栏(260~300px，题集树/目录) + 主区；主区顶部一行统计条
  （《题集名》共 N 题 · 已刷 x/N · 答对 x/N · 已刷 n 轮 · 最近 x/5 · 最佳 x/5 + 右侧计时）
- 「表单卡片」式设置分区：卡片标题（如「进度与范围」「作答设置」）+ 行式控件
  （左描述右控件），底部一行操作钮（预览 / 开始刷题 / 错题回顾）
- 题号栏 = 窄竖条贴主区左缘，数字格，当前题橙底、答错红底、答对绿底
- 题卡 = 白(深色下为 surface)底圆角卡：卡头（考点标题 + 题型 tag + 自评星标 + 动作钮）
    - 题干（LaTeX 公式）+ 解析折叠块 + 选项行（单选/多选；多步题每步一行选项 + 步骤引导语）
- 组件直接借用思源 b3 体系观感（b3-button / b3-list / 下拉框），不自造按钮样式
- 深色下正文不是纯白而是暖米色 #d3cab4；边框和分隔线都是暖沙色低透明——这是 Neo 气质的关键
