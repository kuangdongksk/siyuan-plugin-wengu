20260918 用户贴一批生题输出让我审，我判「无实质缺陷」（该批材料块处理确实合规），用户回：「本来有四十几道题，现在只生成了五道，这就是你说的没缺陷」——真正的丢题在整文档题量层，不在单批输出层。

**Why**：单批协议合规 ≠ 转换质量合格。丢题可能发生在 prompt 口径层（语篇/讲义判定吞题）、分片层（切点漂移）、渲染层，单看一批输出的格式全绿发现不了。用户贴片段给你看时，他的诉求往往是「产量对不对」而不只是「格式对不对」。

**How to apply**：审转换输出先问/先查三本账——①源文档里现成题目数（拉全文数题号行/题号结构）；②产物题集实际题数（bank 存储题集记录）；③差值归因（哪段源没出题、为什么）。对完账再谈单批合规性。参见 [[english-conversion-yield-42-vs-5]]。
