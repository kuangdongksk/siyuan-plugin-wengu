真实内核实测:fill 题 `20260821165017-n87hc7h` 的 `part="answer"` 子块内容是引述块展示文本:

```
> 正确答案：$e^2$
```

而 `grade()` 的 fill 分支是 `answer.split("|").some(accepted === submitted)`,会把整段 `> 正确答案：$e^2$` 当判分原料,用户提交 `e^2` 永远判错。

契约文档自身矛盾:判分规则表说 fill 的 answer 子块应写"纯答案(用 | 分隔可接受答案)",结构示例却画成 `> 正确答案：$e^2$` 展示文本。
