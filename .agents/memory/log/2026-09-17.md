### 核心结论（后续若推进，按此口径）

1. **版权是硬伤，不是「会不会违规」而是分档风险**
    - 判例 (2019)桂0203刑初645号「金考点」题库案：5 人获刑 2–2.5 年 + 罚金 8–10 万，罪名为侵犯著作权罪（题干/选项/解析与权利方逐字一致，3744 名会员）。
    - 刑事门槛（刑法 217 条 + 司法解释）：传播作品合计 500 件以上 / 注册会员 1000 人以上 / 点击 5 万次以上 / 非法经营额 5 万以上即可能够罪 —— 题库型小程序极易触碰。
    - 民事：售价 1.99 元仍判赔 2500 元；大学生扫描卖网盘资料被诉后调解赔付。
    - 三档来源风险：机构自编题（1000题/优题库）＝ 明确受保护，直接复制必侵权；真题＝归属有争议、风险中等；机构写的真题解析＝明确受保护（虹口区法院案例）。
    - **著作权只保护表达不保护思想** → 政治考点本身可用，重写题干/选项/解析才是干净路径。

2. **主体与类目决定能否收费**
    - 个人主体：认证 ≈30 元/年；2026-08-31 起微信开放「虚拟支付-个人」（要求：个人主体 + 身份证 + **类目含「工具」** + 已认证备案；月限额 10 万；Android 费率 1% T+3，iOS 走 Apple 支付 12% / 45–60 天）。即：想收费必须挂「工具」类目，别挂教育。
    - 「在线教育」「题库」类目需企业资质/办学许可，个人与个体户基本进不去。
    - 个体工商户：认证 30 元/年（优惠价，原 300），可开微信支付 → 要正经收费的最优解。
    - 流量主广告：个人可开，需累计 UV ≥1000。

3. **政治内容审核红线**
    - 《微信小程序平台运营规范》3.2.8.5：涉政/煽动性言论不予通过；基本信息规范 2.2 禁政治敏感。
    - 备案环节有前置审批关键词库，个人需签「不涉及前置审批承诺书」；**小程序命名避开「考研」「政治」「教育」「培训」**，用具工具感的名字。
    - 时政类题目为高危区，需敏感词过滤 + 人工逐条复核，不做时政预测。

4. **技术选型**
    - 前端：原生小程序 + TS（推荐）/ Taro 4 / uni-app。Svelte 现有代码无法编译进小程序，UI 层必须重写。
    - 后端：推荐微信云开发。免费环境 3000 资源点/月，但**小程序发布后第 15 天到期**（官方口径，别指望白嫖）；个人版 19.9 元/月（限时，原价 39）。
    - 题库必须放云端：进小程序包＝每次改题都要重新提审。

5. **现有代码复用判断（读过依赖）**
    - 可直接复用：`src/quiz/service/QuestionGrading.ts`（仅依赖 `../../types`）、题型判定（QuestionType / LETTERS / normAnswerText / optionComparable）、错题与轮次数据模型。
    - 必须重写：`render/CardState.ts` 等 —— 依赖 `ui/FormHtml`(statusIcon)、`ui/shared`(esc/fmt)、`service/ProtyleHost`(optionInline 思源解析)、`render/CardHtml`、`render/CardSteps`，与思源 DOM/CSS 变量深度耦合。

6. **时间线**：ICP 备案 7–20 个工作日是不可压缩的关键路径，且 10/1–10/7 假期会拖慢管局审核 → 若真做，注册小程序 + 提交备案必须立即启动。

## 补充：市面实证（飒飒发来「#小程序://政治刷题/...」求解读）

微信短链 `#小程序://名称/短码` 只能在客户端内解析，浏览器/本地都打不开，无法直接查看内容。

但搜索结果实证了这个赛道的真实做法：

- 「阔智考研政治刷题」明确写题库来源含 1000 题、优题库、腿姐 30 天题、米鹏题库
- 「酷酷学刷题」整合肖 1000、精解母题、徐涛优题库、腿姐刷题计划、米鹏、苏一、余峰等十几本
- 「考研刷题通」宣称与肖秀荣 1000 题纸质版、肖四肖八、徐涛腿姐押题卷同步
- 界面截图里直接标注「【肖老解析】」—— 连名师解析署名都照搬

结论：**审核过 ≠ 合法**，这是两条互不相干的线。

- 审核只做形式审查（类目 / 敏感词 / 功能完整性），没有版权比对环节
- 版权属「告诉才处理」，靠权利人投诉（民法典 1195 通知-删除）或起诉触发；没人投诉平台不动手
- 权利人维权性价比低（取证贵、判赔低），优先打大平台而非小程序，小程序封了换名重上
- **风险随规模上升**：做小没人管，一旦有收入有用户就从「不值得起诉」变成「值得起诉」，且同行举报是常规武器

赛道根本矛盾：用户认的是名师题库（肖 1000 / 腿姐 / 徐涛），自命题用户不买账 → 「合法」和「好用」在这个品类里互相排斥。唯一缝隙＝十年真题 + 自写解析。

功能形态参考（截图可见）：章节练习 / 随机练习 / 错题集自动收集 / 收藏 / 笔记（含公开笔记区）/ 刷题排行 / 模拟考试 / 导出 Excel·Word / 夜间模式 / 草稿纸 / 答题卡 / 全站作答次数与正确率 → 与温故 quiz 域能力高度重叠，迁移方向正确；全站统计与排行类功能必须走云端。
