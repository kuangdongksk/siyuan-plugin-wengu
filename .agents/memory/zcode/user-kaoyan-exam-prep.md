用户用温故插件备战考研（2026-08 时点）：习题文档是各家模拟卷，如肖四
肖八（政治）、李林六套、张四张八（数学）。当前在刷的专业课是自动控制
原理（考研 notebook 下，如《1-自动控制的一般概念》《2 拉普拉斯变换》）。
2026-08-23 起英语也在备考范围内（考英语一还是英语二未定，但题型支持
已拍板做通用、不按卷种特判），设计见 [[wengu-english-branch]]；用户
还要求刷英语时能标生词联动背单词、标阅读定位线索给 AI 判。
讲义全部是 **MinerU PDF 导入**：.sy 文件名是裸块 id、标题是中文（这正是
内核按标题匹配路径段会翻车的场景）；插图以 `![](assets/…)` 段落存在
（MinerU 笔记本 assets 有 2000+ 张图）；公式是行内/块级 LaTeX。

**Why:** 解释了他们为什么强调目录需要搜索和分类——几十套模拟卷没有
搜索根本翻不到；也解释了「方框图/电路图题没图」这类问题要往「转换
prompt 丢图」方向查（2026-08-23 已修：prompt 要求插图随题走，需重转）。

**How to apply:** 设计目录/筛选/统计类功能时按「大题量中文短标题」的
场景考虑；搜索目前是标题+路径子串匹配，拼音首字母（xsb→肖八）已提过
但未做，可作为候选增强。处理转换/渲染问题时记住数据特征：文件名≠标题、
图在 assets、公式走 KaTeX。相关：[[wengu-kernel-extra-traps]]
