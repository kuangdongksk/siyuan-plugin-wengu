# .agents/memory —— 温故项目记忆（按模块拆分）

**改哪个域的代码，先读对应模块文件**；模块内口径与 AGENTS.md 同权威。

| 模块文件             | 内容                                                          |
| -------------------- | ------------------------------------------------------------- |
| `quiz.md`            | 做题主流程（揭示态/记账幂等/线索标注/阅读面/材料滚动…）       |
| `mobile.md`          | 移动端刷题（dock 挂载/两段式作答/记账复用口径）               |
| `convert.md`         | AI 转换（逐段自推进/分片并行/词条保真/增量重转换）            |
| `bank.md`            | 题库/专题/知识文档/同义词/路由缓存                            |
| `ai.md`              | AI 基础设施（agentChat 通道/并发闸/prompt 收口/会话面板专题） |
| `word.md`            | 单词域                                                        |
| `siyuan.md`          | 内核 API 工厂                                                 |
| `companion.md`       | 伴学看板娘                                                    |
| `ui.md`              | Svelte 迁移公共积木/样式工具                                  |
| `stats.md`           | 统计域（笔记极薄）                                            |
| `env-debugging.md`   | 通用调试流程 + 两台机器环境与 Shell 坑                        |
| `kernel-pitfalls.md` | 思源内核坑（3.8.x 真机实测）与外部 API 口径                   |
