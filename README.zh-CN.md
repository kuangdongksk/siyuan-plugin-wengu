# 温故 (Wengu)

[思源笔记](https://github.com/siyuan-note/siyuan) 的刷题与背单词插件：
把笔记文档 AI 转成结构化习题集，按章节 / 知识点 / 专题刷题，
错题自动复习，题目与讲义经块引用双向联动，顺手背单词。

> 温故而知新。

## 功能

- **AI 转习题**：讲义文档一键转《标题·习题》题集（AI 先判定能否出题，
  检测 / 生成 / 知识点路由流水线；支持增量重转换——原文改动后只
  重生成变更的小节，按内容指纹对账）
- **刷题**：按文档 / 章节 / 知识点专题刷题，单选 / 多选 / 判断 /
  填空 / 简答分题型作答，客观题自动判分（可 AI 判分），简答自评；
  正计时 / 倒计时 / 不计时，轮次成绩与累计用时随文档保存
- **错题复习**：错题自动进出「温故错题」闪卡卡组（思源间隔重复），
  另有错题本清单按轮次回顾
- **知识树**：AI 归纳章节大纲建知识树文档，生成题自动按知识点挂
  引用，小节级「开刷」「补题」，题目 ↔ 讲义块引用互跳
- **专题管理**：按知识点收集题目成专题（活视图专题随题库实时回流），
  薄弱画像统计
- **背单词**：多词书（内置 CET/考研等，可导入），四步梯记忆
  （英选中 → 中选英 → 听音选义 → 英文回想），错题进度跨书共享
- **统计面板**：ECharts 图表看正确率 / 进度
- **AI 会话面板**：判题 / 转换 / 路由等所有 AI 调用留痕，可回看
  完整问答并继续追问
- **学伴看板娘**：「小书童」悬浮陪伴，表情 + 台词随刷题 / 背单词
  事件联动（规则 + AI 增强）

## 安装

1. 在思源「设置 → 集市 → 插件」搜「温故」安装；或手动：下载本仓库
   Release 的 `package.zip`，解压到 `工作空间/data/plugins/siyuan-plugin-wengu/`。
2. AI 功能（转习题 / 判分 / 知识树 / 学伴增强）依赖思源内置 AI，
   请先在「设置 → AI」配置好模型。

## 使用

- 顶栏闪电图标打开「温故」页签（自动带入当前活动文档的题集）。
- 页签左栏四个入口：**刷题**（文档 / 专题开刷）、**知识**（知识文档
  树 + 专题清单）、**AI 会话**、**学伴**管理。
- 首次刷题前先在页签内「AI 转习题」把讲义生成题集，或导入已有
  结构化题集文档。
- 背单词在右侧 Dock 面板（词典图标）。

## 说明

- 作答统计等运行时数据由插件自托管（存题库数据文件），不污染
  笔记块属性；题目 / 知识小节有内容指纹对账，文档被改动会提示
  更新镜像。
- 所有「删除文档」操作一律进思源回收站，可恢复。

## 开发

```bash
pnpm install
pnpm build   # 产物在 dist/
```

将 `dist/` 拷贝到思源 `data/plugins/siyuan-plugin-wengu/` 即可安装。
开发与调试细则见 [AGENTS.md](AGENTS.md)。
