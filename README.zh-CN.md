# 温故 (Wengu)

[思源笔记](https://github.com/siyuan-note/siyuan) 刷题插件：
导入结构化题集，按章节 / 考点 / 难度刷题，错题自动进入闪卡复习队列，
并通过块引用与讲义笔记双向联动。

> 温故而知新。

## 状态

早期开发中。已可用：页签左侧目录/上方下拉选择**已生成的习题文档**
刷题（习题是真实保存的文档，列表持久），填文档 id 用「AI 转习题」
把讲义生成《标题·习题》（AI 会先判定能否出题）；开刷前可选计时方式
（正计时/倒计时/不计时），轮次成绩（已刷 N 轮 · 最近/最佳）与累计
用时随文档保存；按题型作答（单选/多选点选、判断按钮、填空输入、
简答多行），客观题自动判分，简答自评；错题自动进出「温故错题」
闪卡卡组。

规划：

* [x] 结构化题集导入（AI 转习题：思源 AI 判定 + 生成习题文档）
* [ ] 刷题筛选（按章节 / 考点 / 难度）
* [x] 刷题模式（客观题自动判分，大题自评）
* [x] 错题本（思源闪卡间隔重复）
* [ ] 题目 ↔ 讲义块引用联动
* [ ] 数据库视图统计（分考点正确率、复习进度）

## 开发

```bash
pnpm install
pnpm build   # 产物在 dist/
```

将 `dist/` 拷贝到思源 `data/plugins/siyuan-plugin-wengu/` 即可安装。
