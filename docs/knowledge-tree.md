## 二、剩余四块（按优先序）

### □1 AI 归纳知识树（决策一核心，P1）

现状缺口：层级树是「读已有标题」建树；章节文档本身无规整标题（MinerU 讲义
长文无结构）时依然没树。缺「AI 把章节内容归纳成 h1~h6 大纲」的动作。

- 入口：知识面板文档行「建知识树」（仅 sections 结构单薄时显示，如顶层标题
  数 <3 或全文无 h2+ 层级）。
- 产物：**独立新文档** `{章节标题}·知识树`，与原文同目录，原文一字不动。
  重建=覆盖式重写（错了不伤数据）。
- prompt 层级约定：h1=知识大类（求极限）、h2=方法·解法（洛必达/泰勒/夹逼；
  齐次/非齐次/伯努利/傅里叶）、h3~h6=细分；6 级是余量，实际 3~4 级够。
- 输入预算：超长章节先抽标题/目录，无结构才分段归纳再合并（章节中位
  4.7 万字，全文直喂不稳）。
- 落盘：createDocWithMd 一次成文；树文档与原登记根在面板里合并展示
  （KnowRoots 登记原文档，树文档按标题约定回查关联，或登记侧存映射）。

### □2 生成题打标继承（P1）

现状缺口：变式重练/收集补题生成的题（gen-）零标签，永远进不了知识口径。

- 模板题有 kpRefs → 新题**继承**模板的全部引用（同考点变式，天然同节点）。
- 收集并补题（genIntoCollection）：points 即勾选知识点 → 生成 prompt 附
  该节点标题，产出后确定性挂该节点引用（不依赖 AI 回显格式）。
- 落库点：addGenerated 已收 kpRefs 参数，补调用侧传值即可。

### □3 活视图专题（决策三，P2）

现状缺口：按知识点收集落 qids 死快照，题库后续变化不回流。

- 树节点行「刷此知识点」：物化专题 **id=确定性生成**（`col-kp-{块id}`），
  记录绑定节点 key（BankCollection 加 `nodeKey?`），进入刷题时按节点子树
  引用并集**实时刷新题单**（collectQids 口径）；历史/轮次/统计复用 col:
  机制零新账。手动跨节点专题保持快照语义不变。
- 数据迁移：无（旧专题无 nodeKey 即快照，行为不变）。

### □4 rail 合并（决策四，P3，□3 后做）

- 「专题管理」+「知识文档」两工作区合一：「知识」=上半知识树（节点行：
  刷此节点/匹配/转习题/针对此节点生成/打开）+ 下半手动专题清单（含目录/
  文件夹组织照搬）。rail 收敛为 刷题/知识/AI 会话/学伴。
- WenguWorkspace 枚举减一加一；prefs 里旧值 normalize 落「知识」。

## 三、验收口径

- □1：导入无标题结构的高数章节 → AI 产出「求极限→洛必达/泰勒/夹逼」级树
  并正确渲染层级；重跑覆盖不重复。
- □2：变式重练产出的题在树上节点计数 +1；收集补题的题挂在勾选节点下。
- □3：点节点开刷 → 续跑转补题后重进同节点，题单含新题，轮次历史连续。
- □4：旧 prefs 恢复不落空工作区；专题清单操作与合并前逐项等价。
