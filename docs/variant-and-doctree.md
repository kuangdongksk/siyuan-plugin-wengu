# 变式重练与文档树形化设计审核（2026-08-26）

## 〇、范围与结论

本轮对话（2026-08-26 晚）三个诉求合并设计，**先逐条过再实施**：

1. **变式重练**：二刷时对整卷 AI 题生成「改数字/换条件」的变式卷（生成核已有，缺按卷入口）。
2. **树形文档选择**：知识文档在思源里是分层级的（`/MinerU/基础过关660-数一/高数篇/…`），
   按文档内容生成变式时、以及文档选择器（KnowPicker）里，都应是树形选择而非平铺。
3. **侧栏文档树形化**：温故侧栏现在按 hPath 前缀分组成平铺（一组一文档），应改成树。

「二刷乱序选项」（同轮讨论的另一项）**不在本设计**——装载边界洗牌副本方案已对齐，
独立小项后续单独做。

## 一、变式重练（数字变式按卷生成）

### 现状锚点

| 事实                                                                         | 位置                                            |
| ---------------------------------------------------------------------------- | ----------------------------------------------- |
| variant 生成语义 =「以原题为模板，改数字/换条件/反向提问出同知识点变式题」   | `bank/GenQuestion.ts:50-51`                     |
| 生成核按**知识点**逐点生成（GenPoint），模板取该点错得最多的题               | `bank/GenCore.ts:34-65`                         |
| 现有入口只有两个：薄弱加练（画像驱动）、专题对话框「收集并补题」（缺口驱动） | `bank/WeakDrill.ts`、`bank/CollectionDialog.ts` |
| 单轮生成上限 10（串行 AI，防 token/时长失控）                                | `bank/CollectionDialog.ts:30`                   |
| 内置智能体 agent chat 并发互斥（session busy）；fetchSyncPost 并发互吞       | AGENTS.md 内核坑                                |

### 方案

- **V1 按题生成核（新增）**：现有 GenCore 是「知识点 → 挑模板 → 出变式」；按卷变式是
  「题 → 以它自己为模板 → 出变式」。在 `GenQuestion.ts` 抽出模板题注入段，新增
  `generateVariantOf(qid, modelId)`：prompt 复用 variant 措辞，模板块换成指定题的
  kramdown。生成题 `addGenerated` 入库（来源记 `{卷名}·变式`），与薄弱加练同构。
- **V2 入口**：侧栏文档行**右键菜单**加「变式重练」（与「错题复习」「删除文档」同场，
  交互已有）。点开一个小对话框：范围（整卷 / 仅错题）+ 数量（1~10，默认 10）。
    - 推荐右键而非行内按钮：树化后行内已经很挤（toggle+icon+标题+meta），且右键链路现成。
- **V3 流程**：取范围题列表 → 洗牌取前 N（仅错题时先筛 history 错题）→ 串行逐题
  `generateVariantOf` → 每题生成后即时追加进专题并刷进度 → 完成自动切过去开刷。
  大卷（如 197 题）天然受 N≤10 封顶，做完一批可再开一批（薄弱加练同款节奏）。
- **V4 产物**：落成专题《{卷名}·变式》（每次生成新建，带时间戳后缀防同名合并），
  可在专题管理里删除/移题；轮次会话挂 `col:{id}` 域，与原卷统计互不干扰
  （col 域隔离已落地，见 topic-collection-review §一）。
- **不做**：不改原卷题目本身；不自动连续生成多批；变式题不写回源文档。

## 二、树形文档选择器（KnowPicker 树化）

### 现状锚点

| 事实                                                                                 | 位置                         |
| ------------------------------------------------------------------------------------ | ---------------------------- |
| KnowPicker = 挂 body 的 b3-menu 浮层，关键词搜索 + 平铺列表                          | `ui/KnowPicker.ts`           |
| SQL `type='d'` 按关键词 LIKE，LIMIT 100，无层级展示                                  | `ui/KnowPicker.ts` queryDocs |
| 全库文档树数据：SQL 分页拉全量 `type='d'` 的 id/hpath（无 LIMIT 静默截断 64 行的坑） | AGENTS.md 内核坑             |

### 方案

- **T1 树数据**：首次打开懒加载——`SELECT id, hpath FROM blocks WHERE type='d'` 按
  `LIMIT 100 OFFSET k` 分页串行拉全量（千级文档量级可行），按 hpath `/` 切分建树缓存
  在浮层生命周期内；笔记本文档（hpath 首段）为根。
- **T2 交互（树 + 搜索融合）**：默认展示树（分支可折叠，仅文档行可点）；顶部搜索框
  保留——输入关键词切回平铺结果（现状行为），清空回到树。思源文档树自己的搜索即此
  模式，用户零学习成本。
- **T3 复用面**：转换对话框的知识文档/父文档选择、变式重练若从无上下文处进入时的
  目标选择，都用同一个树组件（多选/单选沿用 KnowPicker 现有 opts）。
- **参考结构**（思源原生文档树 DOM，用户提供的实样）：`ul.b3-list > li.b3-list-item`，
  每行 = toggle（iconRight 箭头，展开旋转 90°）+ icon + text + action；子级嵌套 `ul`，
  行内 `padding-left` 递增缩进。**类名自建 `wengu-tree`**（借结构不借官方类名，防内核
  升级结构变更；UI 标准 §〇4 图标钮/箭头已有同款处理），样式进 panels.scss 全局清单。

## 三、侧栏文档树形化

### 现状锚点

| 事实                                                                           | 位置                                   |
| ------------------------------------------------------------------------------ | -------------------------------------- |
| 侧栏 = 专题组（平铺）+ 每个习题文档一个分组（label=hPath 父路径，item=文档行） | `quiz/CardHtml.ts:225` applySideFilter |
| 文档数据已带完整 hPath（`/MinerU/真橙现控200题/第1章-…`）                      | `quiz/QuestionService.ts:138-163`      |
| 已认定缺陷：`doc:` 源卷影子专题与文档条目在侧栏双显                            | 记忆 wengu-source-col-sidebar-dup      |

### 方案

- **S1 树构建**：`WenguDoc[]` 按 hPath 切分建树——中间路径节点（如 `/MinerU`）即使没有
  对应习题文档也生成纯容器分支；叶子/有题的节点挂文档行（`data-docid` 点击开刷不变）。
- **S2 展开态**：默认展开到**第一层**（笔记本级），更深折叠；展开路径集合存 prefs
  （`sideTreeOpen: string[]`），跨会话记忆。搜索框行为不变（命中过滤时临时平铺展示）。
- **S3 专题区**：保留在文档树上方平铺（专题无层级）；**同时把 `doc:` 影子专题行从侧栏
  隐去**（树化后文档本体已在眼前，双显缺陷顺带消除——专题管理对话框里仍完整可见可删）。
- **S4 右键不变**：文档行右键菜单（错题复习/删除文档/变式重练）挂树行上，委托事件
  已在容器级（`ViewBindings.ts` data-side-body 委托），树化不用重绑。

## 四、实施分期（建议）

1. **一期**：V1~~V4 变式重练 + S1~~S3 侧栏树（互相成就：树行右键即变式入口）。
2. **二期**：T1~T3 KnowPicker 树化（独立受益，转换选文档更顺）。
