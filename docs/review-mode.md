# 错题复习模式 + 统计增强 设计审核稿

> 2026-08-25 · 分支 `wengu/review-mode` · 状态：**已定稿（D1~D6 全部拍板，同日）**
> D1=右键单入口（头部切换器 20260826 删，见 §二 D1 v3）；D2=文档主源（弃题库）；D4=最近一次对即掌握；
> D5=按文档重刷（弃跨文档专题，顺手修 P2-6）；D6=统计四项全要。

## 〇、背景与现状缺口

用户反馈：**统计太简陋**、**做错的题没法复习（没有回看模式）**。

现状盘点（调研结论）：

| 能力     | 现状                                                                             | 缺口                                                                |
| -------- | -------------------------------------------------------------------------------- | ------------------------------------------------------------------- |
| 错题数据 | 块属性 `wrong-count`/`right` + 会话 history 逐题记录（含 AI 评语/错因）都在      | 无跨轮错题索引、无题目级错因回看                                    |
| 错题重刷 | 开刷面板「只刷上次错题」（StartPanel `scope:"wrong"`）                           | **只取上一轮**错题，跨卷/历史累计错题刷不到                         |
| 错题浏览 | 统计面板文档详情页有错题清单                                                     | 上限 50 条、仅当前文档、只有摘要，看不了「我当时答了什么/为什么错」 |
| 统计     | 总览 5 数字卡 + 正确率折线 + 文档榜                                              | 无错题消化情况、无知识点/错因维度（薄弱画像只在收卷报告露 Top8）    |
| 模式框架 | `QuizView.mode` 已留 `"quiz"\|"review"\|"study"` 开口（M6），review 分支渲染空白 | 恰好是复习模式挂载点                                                |

关键有利条件：块属性 `wrong-count`/`right` 就是事实源（随文档走），
SQL 直查即可得全局错题 qid 清单；会话 history 里有逐题历次答案/AI 评语/错因。

## 一、方案总览

两件事：

1. **错题本（复习模式，`mode="review"`）**：侧栏文档右键入口
   （20260826 起唯一入口，头部「做题|复习」切换器已删——样式不达标且
   头部信息行拥挤，用户拍板删除）→
   跨文档错题清单 + 单题回看（历次作答时间线 + AI 评语/错因 + 答案解析 + 跳源块）；
   重刷按文档进行（开刷面板新增「错题重刷」范围）。
2. **统计增强**：总览 tab 加「错题概况 / 薄弱知识点 Top / 错因分布」三块；文档详情错题清单行可点击直达错题本该题。

**零新增持久存储**（本轮）：掌握状态由现有数据推断；间隔复习（Leitner）挂账。

## 二、逐条设计决策

### D1 错题本入口与形态（v3，2026-08-26 修订：头部切换器删除）

**单一入口**：侧栏文档列表项右键 → 「错题复习（N 题）」→
进入复习模式并预筛该文档的错题（跨文档总览用筛选器切走即可）。
文档树（思源侧）右键不加，避免与内核菜单搅和，插件侧栏够用。

~~v2 的头部「做题 | 复习」分段切换器~~（2026-08-25）已于 2026-08-26
删除：实际渲染样式不达标（b3-segmented 是自造风格、与原生不贴），
且头部信息行（目录开关+文档信息+轮次+结束本次+计时）已拥挤。
switchMode/会话恢复机制保留，仅去 UI——将来要回入口先读此节。

复习态头部显示「错题本 · 未掌握 N / 已掌握 M」摘要行。

### D2 错题清单数据源与条目（v2，2026-08-25 拍板：以文档为主源，弃题库）

**原则：块属性是唯一事实源，衍生数据只落 qid 维度，不复制题目内容，不碰 bank。**

- **错题发现**：SQL 直查 attributes 表 `custom-plugin-wengu-wrong-count > 0`
  （写法仿 listQuestionDocs 的聚合 SQL，join blocks 拿文档归属与题干行），
  **显式 LIMIT/OFFSET 分页**（内核无 LIMIT 截断 64 行坑）。题块删除即自然
  从错题本消失——无「源已删」态，语义干净。
- **掌握徽标**：块属性 `right` + `wrong-count` 推断（D4 口径不变，
  数据源就是漏斗直写的事实源）。
- **清单条目**：qid、文档标题、题型、错次、最近错时（块属性无时间，
  取 history 索引的最近一条）、掌握徽标、错因徽标（时间线最近错因）。
- **题目内容（回看详情/重刷）**：按 qid 回源取——`getChildBlocks`/
  `getBlockKramdown` 复用 hydrate 语义拼题干/选项/答案/解析，
  **惰性加载**（点开一题才取一题，fetchSyncPost 串行天然合规）。

~~v1 以 bank.records 镜像为主源的方案废弃~~（题库是按文档走的镜像，
不是事实源；且避免 kramdown 双解析路径）。

### D3 单题回看内容

点清单条 → 右侧回看面板：

1. **题目**：题干 + 选项（按 qid 回源 `getChildBlocks` → hydrate 语义拼装，
   Lute 静态渲染 + KaTeX；不挂可编辑 Protyle，回看只读；点开惰性加载）；
2. **历次作答时间线**：打开错题本时扫一遍 `history.sessions` 建内存索引
   （`qid → [{时间, 我的答案, 对/错/partial, AI 评语, 错因}]`，`qid#k` 归并整题）；
   每次一行，最新在上；
3. **正确答案 + 解析**：hydrate 出的 answer/solution 子块（回源同 D2）；
4. **跳源块**：`siyuan://blocks/{qid}`（右键反查已验证该路径）。

**待拍板 D3**：时间线全量扫描的量级（考研模拟卷，sessions 数量级几十~几百，
每轮 results 数十，内存索引一次性构建可接受）；如担心，可只索引错题相关 qid。

### D4 掌握度判定（零存储版）

- **未掌握**：`wrongCount ≥ 1` 且最近一次 `right = "0"`（partial 记错，口径同统计）。
- **已掌握**：`wrongCount ≥ 1` 且最近一次 `right = "1"`（错过但最近对）。
- 「重刷未掌握」清单 = 未掌握集合。

**已拍板 D4（2026-08-25）**：按推荐——「最近一次对」即算掌握；
「连续 2 次对才算」从严版挂账（错题重刷答对后徽标即时变绿，反馈闭环）。

### D5 「重刷」机制（v2，2026-08-25 拍板：只刷当前文档，弃跨文档动态专题）

**架构事实：温故刷题是文档驱动的**——session、轮次历史、渲染全挂 docId，
专题最终也是一个文档，作答只发生在文档上下文里。因此：
错题本的「**看**」是全局的（跨文档清单回看），「**刷**」是按文档的。

- **开刷面板 scope 加一项**：「错题重刷（未掌握 N 题）」——来源 = 当前文档
  块属性 `right="0"` 且 `wrong-count>0` 的题（从已装载的 fullList 过滤即可，
  零新增查询）。现有「只刷上次错题」保留（刷完卷马上重刷刚错的几题是独立场景）。
- **错题本清单按文档分组**，组头「重刷本文档未掌握（N）」→ 跳该文档
  （selectDoc）+ 预选该 scope 开轮。
- 错题重刷轮照常入该文档轮次历史（与现有 scope:"wrong" 同语义，不搞特殊）。
- **顺手修 P2-6**：既然动 `RoundConfig.scope`，给 `WenguSession` 落 `scope` 字段，
  「继续上次」按 scope 恢复清单（错题重刷中断后不再展开为全量）。
- **弃**：跨文档动态专题、临时 collection 条目、按 qid 收集内容构造清单——
  CollectionFlow 整个不动。

~~v1 跨文档动态专题方案废弃~~。

### D6 统计增强内容（总览 tab 三块 + 一处联动）

1. **错题概况卡**：未掌握 N / 已掌握 M 两数字 + 「进错题本」按钮（切 review 模式）；
2. **薄弱知识点 Top8**：`weakness.topSync(8)` 现成数据，列表样式同收卷报告
   （wrong/total + 错因徽标），点击无动作（或后续联动筛选错题本）；
3. **错因分布**：weakness points 按六键聚合 wrong 数，CSS 条形（复用 `wengu-bars`
   样式，不新增图表实例）；
4. **联动**：文档详情 tab 的错题清单行 → 点击关面板并打开错题本定位该题回看。

**已拍板 D6（2026-08-25）**：四项全要；每日答题量日历热图（打卡感）
本轮不做挂账。

## 五、风险与注意

- **SQL 64 行截断坑**：全局错题查询必须显式 `LIMIT n OFFSET k` 分页循环取完；
- **fetchSyncPost 串行**：详情惰性逐题取（getChildBlocks/getBlockKramdown）
  天然串行，不做并发；
- 时间线索引构建在页签打开时同步做，注意大 history 下 UI 不卡（数据量级见 D3）；
- Neo 主题验证：错题本两栏布局按 Neo 下无横向滚动条复查（config__side 坑）。
