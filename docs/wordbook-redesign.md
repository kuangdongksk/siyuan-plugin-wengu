## 〇、现状基线（本方案建立在其上）

- 回想题正面直接三档大底条（认识/模糊/忘记，占满底部、56px 高、键盘 1/2/3），
  选完翻面看详情；结果页底部「下一个 + 记错了」。
- 「记错了」= 强制按不认识批改进误认本 + 弹「认成了…」自述框；选「忘记」
  直接带出自述框。客观题（选择/拼写）答错后同为「下一个 + 记错了」。
- 空格/点卡静默翻面时结果页保留三档兜底；右上角工具组：星标 + 熟 +
  回首页（列表图标，刷卡中途随时退出，重进按到期/新学重新构队）。
- 四步梯已接线并部署（20260828 提交链）；现行建队为静态流水线
  `pipelineLadder`（§二 将换为滚动窗口）。
- 复习排期现行 Leitner 固定阶梯 `INTERVAL_DAYS=[1,2,4,8,16,32]`（§三 将
  换为 FSRS）。

## 一、发音（朗读）

- **技术**：浏览器 `speechSynthesis`（Electron/Chromium 内置 TTS），
  念英文单词，`en-US`、语速 0.9。零依赖零费用，离线可用。
- **限制**：音色取系统嗓音（Windows 为 Microsoft David/Zira，一般）；
  **词库无音标数据**（只有 `[单词, 释义]`），音标列不做——要真音标须
  MinerU 重跑 OCR 管线（要 token，挂账不做）。
- **落点**：
    1. 听音题（梯③）进卡自动播一次 + 题面中央「重听」大按钮；空格=重听。
    2. 跟读题（梯④）进卡自动播 + 词面旁小喇叭（wengu-iconbtn）。
    3. 其余显示单词的卡：详情区（翻面后）加小喇叭，点了重念。
- **备选挂账**：接词典 API 拉真人音频+音标——需网络与 key，不进本期。

## 二、新词会话内四步梯——滚动窗口调度（20260828 定稿）

新词（本会话未学且无历史状态）在会话内按步出题。**梯序采用口述版**
（原参考流草案 choiceEn→recallEn→listen→readalong 作废）：

| 步         | 题型              | 题面                             | 操作                                             |
| ---------- | ----------------- | -------------------------------- | ------------------------------------------------ |
| ① 英选中   | choiceEn（现行）  | 单词大字 + 四选一释义            | 想不起来「**看答案**」直接翻底按答错计，见 §二.1 |
| ② 中选英   | **choiceZh 接线** | 释义 + 四选一单词                | 同上                                             |
| ③ 听音选义 | **listen（新）**  | 喇叭按钮（单词隐藏）+ 四选一释义 | 自动播+空格重听+「看答案」                       |
| ④ 英文回想 | recallEn 三档     | 只给单词                         | 认识/模糊/忘记三档大底条                         |

1. **看答案**：选择题/听音题正面的小字钮，点了 = `answered{correct:false,
peek:true}` → 正确项高亮 + 详情 + 「下一个/记错了」，反馈文案
   「看了答案（按不认识计）」。
2. **前进规则（20260828 用户加严定稿）**：仅「认识」进下一步；模糊/
   忘记/答错/看答案 = 该词**梯清零回①**（词尾四点实时回落）。窗口制下
   清零词留在窗口重新排队，天然支持重走——原静态流水线的「按缺口补插」
   机制随本节一并作废。
3. **滚动窗口（20260828 口述定稿，取代静态流水线）**：
    - **动机**：静态预排把整场新词 ×4 步一次性排成上万位长队（「剩
      10963」事故根源），归零补插是对静态表的打补丁；换为**每张卡现场
      决策**的滚动窗口——手上只保持少量在学词，新词渐进进、在学词错峰
      走深，循环渐进（主流背单词 App 的标准结构）。
    - **单批连续流（20260828 定稿）**：滚动序列**只有一批**——从 cursor
      起一条连续流到用户停止/全书学完，不再有「组宽≤4」的流水线组、
      不再按组重排。AI 组复盘与队列结构解耦：改为**每毕业 groupSize 个
      词**触发一次复盘（毕业数累计持久，复盘只是汇报边界，不动队列）。
    - **进度跨批保存（20260828 定稿）**：在学窗口的梯进度**持久化**
      （words.json `ladder` 记 在学词→步数，见 §三 schema v2）。中途退出
      重进新学会话，窗口按持久步数**原样恢复续背**——走到②的词从②
      继续，不因退出回①；上次出镜间隔不持久（重进后重新起算）。
    - **在学窗口**：容量**可配置**（默认 5，范围 3~~10）。窗口内 = 已开词
      集合，各带梯进度 0~~4 与上次出镜卡序。
    - **开局冷启动**：窗口未满且无就绪词时连出新词①（英选中·先测后学）
      ——开局头几张连教，攒够在学词后自然进入轮转（「所有的都是四选一：
      给英文选中文」阶段）。
    - **每张卡决策（自然流动）**，按序取第一条命中：
      a. 窗口内有**就绪词**（梯未走完 且 距上次出镜 ≥3 张，REINSERT_GAP
      沿用）→ 推进其中**最久未出镜**的词走下一步；
      b. 无就绪词且窗口未满 → **引入新词**①；
      c. 无就绪词且窗口已满 → 取窗口内最久未出镜的词垫场（极端兜底，
      等价放宽就绪）。
    - **毕业**：某词在④评「认识」→ 出窗：cursor 前移、按 §三 初始化
      FSRS、腾出窗位给下一个新词。
    - **复习词不混入**（新学/复习分会话，现行不变）。
4. 降级保护：干扰项凑不满 4 个时选择/听音退回想（中选英退中文回想）。
5. **跟读 readalong 挂账**：末步定为英文回想，readalong 定义保留未接线。
6. **「剩」语义**：窗口制下队列即词——头部「剩」= 当前书剩余未学词数
   （随毕业递减）。会话无长度上限（背到用户主动停）；「每日新词上限」
   留作后续可选设置（挂账）。

## 三、复习排期：FSRS（20260828 定稿方向）

- **动机**：现行 Leitner 阶梯无逐词自适应；且新学梯每步都推长期档位
  ——10 分钟走完①~④全对即「8 天后再见」，与隔周连对四次的词拿同排期
  （虚高根因）。业界标准两层结构：会话内短期循环（§二滚动梯）管短期
  记忆，FSRS 管跨天长期调度。
- **技术**：`ts-fsrs`（open-spaced-repetition 官方 TS 实现，FSRS 6，
  MIT，ESM/CJS/UMD）。调度核是 D/S/R 三量公式，轻；**默认参数起步**
  （平均略优于 SM-2），优化器不吃。
- **数据模型（words.json v2）**：
    - 每词 `[档位,到期]` → `{d, s, due}`（Difficulty/Stability/到期）；
    - 新增 `reviews` 逐词流水 `{ts, r:1|2|3, dl}`（时间/评分/当时间隔天）
      ——为将来参数优化留料（Anki 经验约 400 条起效）；优化器（wasm 端跑
      或导出离线）**无限期挂账**；
    - 新增 `ladder`（在学词→梯步 0~4，存在即在窗口）——§二.3 进度跨批
      保存的落点；同字段兼任「重进恢复」与「窗口成员表」；
    - **存量迁移**：旧档位 lv → S=旧阶梯天数（`INTER_DAYS[lv-1]`）、D=5
      （误认 ≥2 次 → 6.5）、due 保留；simple/familiar/starred/误认本不动
      （在途梯进度无存量可迁，首次升级后从当前会话开始记）。**迁移代码
      为一次性过渡：20260828 用户确认存量落盘后已移除**，存储现只认
      version 2，认不出的文件按新进度起步。
- **映射**：认识→Good、模糊→Hard、忘记→Again（Easy 不用）；目标记忆率
  0.9 起步（后续设置项）。
- **毕业初始化**（接 §二）：按滚动梯会话表现定初值——0 错毕业→Good 档、
  错过→Hard 档、整梯重来 ≥2 次→Again 档（实现时取 ts-fsrs 默认 w 对应
  首评稳定度）。
- **解耦**：新学梯**步进不再调 FSRS**——短期循环不污染长期排期。
- **不变项**：复习侧五题型轮换、到期队列 = due≤now 书序、「明天 N」
  口径、AI 复盘画像。

## 四、标题与书名

- 头部主标题固定「**温故单词**」（替换现在的《你还在背单词吗（刘晓艳·2026）》）。
- 当前书名挪到副位：标题右侧/统计行小字显示（如 `温故单词 · 刘晓艳2026`）。
- 现状 title 硬编在生成物 `wordbook-meta.ts`；多词书后书名 = 当前书
  `name` 字段，不再读生成物常量。

## 五、多词书导入与切换

动机：可能备考多个考试（考研英一/二、六级等），需要多本词书切换。
方向对齐早前定稿：**考试=进度域 / 书=带序子集 / 进度挂归一化词头**。

- **概念模型**：
    - 词书 `{id, name, words:[{w,m}], units?}`；内置《你还在背单词吗》为首本
      （首次启动落盘一份，后续与用户导入的同权管理）。
    - 进度 key 从「词在书内的下标」改为**归一化词头**（小写、去空格/连字符），
      同词跨书共享进度——这是本节核心改造点（存量 words.json 需迁移）。
- **存储**：工作区文件 `data/wengu/wordbooks/{id}.json`（putFile/getFile 走
  KernelFile 工厂；目录沿用「词表不走思源块」的既定约定）。
- **UI**：
    - 头部书名副位 = 选择器（点击弹官方风格浮层列书切换，样式同模型选择器）。
    - 起点设置面板加「词书」组：导入、设为当前、删除（删书不删进度）。
- **导入格式**：`.json`（`[{w,m}]`）或 `.csv`（`词,释义`，UTF-8）；不背单词
  App 导出走现行进度导入入口，不混。
- **切换行为**：存当前进度 → 换书 → 队列重建（到期复习+新词按新书重算）；
  「今天/明天 N」按当前书统计。
- **版权注记**（wordbook-lxy §版权）：内置词表仅限自用；若上思源集市须移除
  内置书、全靠用户导入——多词书导入正是前置解法。
- **第一版简化建议**：先做**单层书列表+切换**（进度天然挂词头已够共享），
  「考试」显式分层（一个考试挂多本书）等真有第二本书再上。
